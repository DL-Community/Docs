# 自定义后期处理

<!-- last-modified -->

> [!IMPORTANT]
> **兼容性**<br>DLCE v3.5.0 及以上

## 创建文件
- 新建一个文本文件，按照下面的格式[重命名文件](#文件命名)；
- 参考下方的[后处理特效](#后处理特效)说明向文件中加入你想要使用的效果；
- 数值修改完毕后，参考[导入](#导入)说明，将文件重命名并导入至游戏路径中。

## 文件命名
- 文件名格式为 `关卡代号.postprocessing`。
- `关卡代号` 用于指定该配置将会用于哪一个关卡。请将 `关卡代号` 替换为实际的代号。
比如，将 `关卡代号` 替换为 `Taurus`，则游戏会将你的配置文件应用在**金牛座**关卡中。
- 完整的代号清单详见[关卡信息](/dlce/level_information.md)。
- `关卡代号` 必须使用指定的名称，否则不会正常读取。
- 游戏允许同时导入多个配置文件，并自动应用到 `关卡代号` 对应的关卡上。

## 导入
<!-- tabs:start -->

### **Windows**
- 前往游戏安装目录（安装时指定的路径）。
- 后期处理配置文件保存在如下路径中

```directory
游戏安装目录/Dancing Line_Data/Custom/PostProcessing/关卡代号.postprocessing
```

### **macOS**

- 打开访达 Finder，按下 ` ⌘ ⇧ G` 输入如下路径后回车

```directory
~/Library/Application Support/YINSU Studio/Dancing Line/
```

- 后期处理配置文件保存在如下路径中

```directory
Custom/PostProcessing/关卡代号.postprocessing
```

### **iOS**
- 打开“文件”app，找到“我的 iPhone”
- 后期处理配置文件保存在如下路径中

```directory
跳舞的线/Custom/PostProcessing/关卡代号.postprocessing
```

### **iPadOS**
- 打开“文件”app，找到“我的 iPad”
- 后期处理配置文件保存在如下路径中

```directory
跳舞的线/Custom/PostProcessing/关卡代号.postprocessing
```

### **iOS on Mac**
- 打开 Finder 访达，按下 ` ⌘ ⇧ G`，输入下列路径并回车：

```directory
~/Library/Containers
```

- 找到游戏文件夹，进入 `Data/Documents` 文件夹。
- 后期处理配置文件保存在如下路径中

```directory
Custom/PostProcessing/关卡代号.postprocessing
```

### **Android**

- 后期处理配置文件保存在如下路径中

```directory
/storage/emulated/0/Android/data/com.AaronJ.DancingLine/files/Custom/PostProcessing/
```

## 配置文件语法

| 类型                            | 介绍                                                                                                               | 示例                                                                                                |
|-------------------------------|------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| `; 文本`                        | 所有以英文分号开头的文本均为注释，仅作为备注用途，存在与否不会影响配置文件。                                                                           | -                                                                                                 |
| `[Section]`                   | 带有方括号的为 分区 标记，用于区分下列配置项归属于哪个特效。对顺序不敏感，打乱每个 Section 的顺序不会影响配置文件。                                                  | `[Ambient Occlusion]`                                                                             |
| `Property=Value`              | 配置项，等号 `=` 左侧为配置项的名称，右侧为配置项的数值。                                                                                  | `Intensity=0.00`                                                                                  |
| Color<br/>`#RRGGBB`           | 16进制颜色（RGB），在配置项的右侧，以井号 `#` 开头，用于需要设置颜色的配置项。                                                                     | `#FF00FF` 表示 R 通道为 255，G 通道为 0， B 通道为 255。                                                        |
| Color<br/>`#RRGGBBAA`         | 16进制颜色（RGBA），在配置项的右侧，以井号 `#` 开头，用于需要设置颜色的配置项。                                                                    | `#FF00FFFF` 表示 R 通道为 255，G 通道为 0，B 通道为 255，Alpha 通道为 1。                                           |
| Color<br/>`#RRGGBB:Intensity` | 16进制 HDR 颜色（RGB），在配置项的右侧，以井号 `#` 开头，用于需要设置 HDR 颜色的配置项。<br/>`Intensity` 为颜色强度，允许负数，使用冒号 `:` 分割16进制 RGB。强度越高，颜色越亮。 | `#FFFFFF:0.0` 表示 R 通道为 255，G 通道为 255，B 通道为 255，Intensity为 0 的正常白色。                                |
| Boolean                       | 布尔值，只有 `true`（开） 和 `false`（关）两种状态，通常用于只有两种状态的配置项，例如开关。                                                           | `Fast Mode=false` 表示关闭 Fast Mode。                                                                 |
| Vector<br/>`x,y`              | 二维向量，使用英文逗号 `,` 间隔每一个维度，用于定义位置或方向。                                                                               | `Center=0.5,0.5` 表示 Center 位置为 (0.5, 0.5)。                                                        |
| Vector<br/>`x,y,z` `r,g,b`    | 三维向量，使用英文逗号 `,` 间隔每一个维度，用于定义位置、方向或 RGB 颜色（对应XYZ）。                                                                | `Red Channel Mixer=100,0,0` 表示 Red Channel Mixer 颜色的 R 值为 100， G 值为0， B值为0。                       |
| Float                         | 浮点数（小数）。                                                                                                         | `11.00`                                                                                           |
| Integer                       | 整数。                                                                                                              | `11`                                                                                              |
| Enumeration                   | “枚举值”，通常用于定义某个属性的模式，可以是数字或对应的英文名称。                                                                               | 以下文 Ambient Occlusion 的 Mode 属性为例，`Mode=0` 或 `Mode=ScalableAmbientObscurance`，这两种写法都表示将 Mode 设为0。 |


## 后处理特效

> [!TIP]
> 大多数情况下，你并不需要开启全部特效，下列每一个特效或配置项都不是必需品。
如果删除整个特效，游戏会彻底关闭此特效。如果删除某个配置项，游戏会自动应用其默认值。
如果不需要修改某个配置项，请将其从配置文件中移除以提升配置文件读取速度。

### Ambient Occlusion

> **环境光遮蔽（AO）**，开启该特效可在物体边缘绘制阴影，增加画面层次感。

<img height="300" src="/Docs/lib/img/PostProcessing/AmbientOcclusion.png" alt="Ambient Occlusion Sample">

> [!TIP]
> 环境光遮蔽不应过强，否则会导致画面变黑变脏，影响视觉效果。

```ini
; 下方参数均为默认值，直接套用将不会有任何效果

[Ambient Occlusion]
Mode=ScalableAmbientObscurance
Intensity=0.00
Radius=0.00
Quality=Medium
Thickness Modifier=1
Color=#000000
```
| 配置项                  | 介绍                                                                                                                                                                            | 取值范围                                                                                                                                                   |
|----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Mode`               | 环境遮光蔽的算法。<br/>`1`=`MultiScaleVolumetricObscurance`能使PC端质量更高、速度更快、需要计算着色器的支持。                                                           | Enumeration<br/>`0`: `ScalableAmbientObscurance`<br/>`1`: `MultiScaleVolumetricObscurance`                                                             |
| `Intensity`          | 暗度强度，数值越高暗部越深。                                                                                                        | Float<br/>`0.00 ~ 4.00`                                                                                                                            |
| `Radius`             | 采样点半径，影响阴影扩散的范围。                                                                                                         | Float<br/>`-999.00 ~ 999.00`<br/>*仅在 `Mode` 为 `0` 或 `ScalableAmbientObscurance` 时有效                                                                    |
| `Quality`            | 采样点数量，最低、低和中等的采样通道均是下采样，而高、最高则不采用且只应用于高端，质量越高阴影过渡越平滑，性能消耗也越大。 | Enumeration<br/>`0`: `Lowest`<br/>`1`: `Low`<br/>`2`: `Medium`<br/>`3`: `High`<br/>`4`: `Ultra`<br/>*仅在 `Mode` 为 `0` 或 `ScalableAmbientObscurance` 时有效 |
| `Thickness Modifier` | 负责修改遮挡物的厚度，增加暗部的大小并产生光晕。                                                | Float<br/>`1.00 ~ 10.00`<br/>*仅在 `Mode` 为 `1` 或 `MultiScaleVolumetricObscurance` 时有效                                                                   |
| `Color`              | 自定义暗部阴影的颜色，营造出特殊的氛围，默认效果为纯黑。                                        | Color<br/>`#RRGGBB`                                                                                                                                    |

<!-- tab:外发光 -->
### Bloom

> **物体外发光效果**，也叫**光溢出**，用于模拟物体在高亮度情况下的发光效果。

<img width="500" src="/Docs/lib/img/PostProcessing/Bloom.png" alt="Bloom Sample">

> [!TIP]
> 外发光过强会导致画面过亮变糊，不推荐过度使用。

```ini
; 下方参数均为默认值，直接套用将不会有任何效果

[Bloom]
Intensity=0
Threshold=1
Soft Knee=0.50
Clamp=65472
Diffusion=7
Anamorphic Ratio=0
Color=#FFFFFF:0.0
Fast Mode=false
```
| 配置项                | 介绍                                                                                                                                                                                                                         | 取值范围                          |
|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------|
| `Intensity`        | 外发光的强度大小，当其值大于<br/>`1`时则贡献出更多的能量。                                                                                                            | Float<br/>`0.00 ~ ∞`          |
| `Threshold`        | 亮度取值范围，只有关卡内亮度超过该值的区域才会产生外发光泛光效果。                                                                                                                                                | Float<br/>`0.00 ~ ∞`          |
| `Soft Knee`        | 让阈值附近的亮光像素平滑过渡，避免生硬切割，<br/>`0`为软平滑过渡，<br/>`1`为硬平滑过渡。                                                                                                                   | Float<br/>`0.00 ~ 1.00`       |
| `Clamp`            |在游戏内限制亮光像素来控制外发光的数量。                                                                                                                                                        | Float<br/>`-∞ ~ ∞`            |
| `Diffusion`        | 决定辉光扩散程度范围，建议采用整数值，从而让光芒更柔和，但由于其内部迭代计数，不因将其光照动画化，不然会带来光照半径的问题。| Float<br/>`1.00 ~ 10.00`      |
| `Anamorphic Ratio` | 外发光的变形比例，能产生类似电影镜头的光晕拉伸效果，其负值为垂直拉伸，正值为水平拉伸。                                                                                                   | Float<br/>`-1.00 ~ 1.00`      |
| `Color`            | 自定义外发光的整体色调，给予外发光统一的着色且控制其强度，默认效果为纯黑。                                                                                                                                                                                           | Color<br/>`#RRGGBB:Intensity` |
| `Fast Mode`        | 快捷模式，旨在于对移动端或者其他低端设备降低质量提升性能，而PC端或高端设备也可以用于提升性能。                          | Boolean<br/>`true` `false`    |

<!-- tab:色彩分级 -->
### Color Grading

> **色彩分级**，用于调节画面颜色。

> [!TIP]
> 色彩分级若过于严重可能会让画面花里胡哨。

```ini
; 下方参数均为默认值，直接套用将不会有任何效果

[Color Grading]
Mode=HighDefinitionRange
Tonemapping Mode=None
Temperature=0
Tint=0
Post-exposure (EV)=0
Color Filter=#FFFFFF:0.0
Hue Shift=0
Saturation=0
Contrast=0
Red Channel Mixer=100,0,0
Green Channel Mixer=0,100,0
Blue Channel Mixer=0,0,100
```

| 配置项                   | 介绍                                                                                                                                                                                                                                                                                                 | 取值范围                                                                                                                  |
|-----------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| `Mode`                | 选择适合设备的动态效果，即色彩分级的模式，如果设备支持HDR且显示屏也支持，建议使用。若为低端设备不支持HDR，建议使用<br/>`External`。 | Enumeration<br/>`0`: `LowDefinitionRange`<br/>`1`: `HighDefinitionRange`<br/>`2`: `External` (不支持)            |
| `Tonemapping Mode`    | 选择画面色彩映射的算法模式。                                                                                                                                                                                                                     | Enumeration<br/>`0`: `None`<br/>`1`: `Neutral`<br/>`2`: `ACES`                                                        |
| `Temperature`         | 白平衡色温，正值越高色彩越黄，负值越低色彩越蓝。                                                                                                                                                                                                                                              | Float<br/>`-100.00 ~ 100.00`                                                                                          |
| `Tint`                | 对白平衡色温的补偿色彩，正值越高色彩越红，负值越低色彩越绿。                                                                                                                                                                                                                                  | Float<br/>`-100.00 ~ 100.00`                                                                                          |
| `Post-exposure (EV)`  | 整体色彩曝光调整，以EV为单位，在HDR显示后、色彩映射前应用。                                                                                                                        | Float<br/>` -∞ ~ ∞`                                                                                                   |
| `Color Filter`        | 色彩颜色滤镜，通过乘法叠加色温。                                                                                                                                                                                                                                                            | Color<br/>`#RRGGBB:Intensity`                                                                                         |
| `Hue Shift`           | 对整体色彩进行偏移，值越大色彩反转越高。                                                                                                                                                                                                                                                                       | Float<br/>`-180.00 ~ 180.00`                                                                                          |
| `Saturation`          | 色彩饱和度。                                                                                                                                                                                                                                                              | Float<br/>`-100.00 ~ 100.00`                                                                                          |
| `Contrast`            | 色彩对比度。                                                                                                                                                                                                                                             | Float<br/>`-100.00 ~ 100.00`                                                                                          |
| `Red Channel Mixer`   | RGB红色通道混合器。                                                                                                                                                                                                                            | Vector<br/>`r,g,b`<br/>`r`:`Float -200.00 ~ 200.00`<br/>`g`:`Float -200.00 ~ 200.00`<br/>`b`:`Float -200.00 ~ 200.00` |
| `Green Channel Mixer` | RGB绿色通道混合器。                                                                                                                                                                                                                          | Vector<br/>`r,g,b`<br/>`r`:`Float -200.00 ~ 200.00`<br/>`g`:`Float -200.00 ~ 200.00`<br/>`b`:`Float -200.00 ~ 200.00` |
| `Blue Channel Mixer`  | RGB蓝色通道混合器。                                                                                                                                                                                                                           | Vector<br/>`r,g,b`<br/>`r`:`Float -200.00 ~ 200.00`<br/>`g`:`Float -200.00 ~ 200.00`<br/>`b`:`Float -200.00 ~ 200.00` |

<!-- tab:色差 -->
### Chromatic Aberration

> **色差**，模拟相机镜头散射现象，使得物体边缘产生类似彩虹的颜色

<img height="300" src="/Docs/lib/img/PostProcessing/ChromaticAberration.png" alt="Chromatic Aberration Sample">

> [!TIP]
> 色差过重会让整体画面失调。

```ini
; 下方参数均为默认值，直接套用将不会有任何效果

[Chromatic Aberration]
Intensity=0
Fast Mode=false
```

| 配置项         | 介绍                                                                                                                                                                                                | 取值范围                       |
|-------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------|
| `Intensity` | 色差的强度大小。                                                                                                                                                                  | Float<br/>`0.00 ~ 1.00`    |
| `Fast Mode` | 快捷模式，旨在于对移动端或者其他低端设备降低计算精度提升性能，而PC端或高端设备也可以用于提升性能。 | Boolean<br/>`true` `false` |

<!-- tab:景深 -->
### Depth of Field

> **景深**，模拟人眼的聚焦与模糊效果。

<img height="300" src="/Docs/lib/img/PostProcessing/DepthOfField.png" alt="Depth of Field Sample">

> [!TIP]
> 景深过浅会导致画面模糊，过深会导致画面过于细化。

```ini
; 下方参数均为默认值，直接套用将会使用默认效果

[Depth of Field]
Focus Distance=10
Aperture=5.6
Focal Length=50
Max Blur Size=Medium
```
| 配置项              | 介绍                                                                                                                                                                                       | 取值范围                                                                                 |
|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| `Focus Distance` | 决定清晰点的位置，以关卡画面坐标计算，根据其中重要物体位置来调整。                                                                                                                                                          | Float<br/>`0.10 ~ ∞`                                                                 |
| `Aperture`       | 光圈值（f-stop或f-number），光圈值越大，即该效果值越小，模糊越明显。                                                                          | Float<br/>`0.10 ~ 32.00`                                                             |
| `Focal Length`   | 从镜头到胶片的距离计算，数值越大，景深越浅。                                                                                    | Float<br/>`1.00 ~ 300.00`                                                            |
| `Max Blur Size`  | 控制最大散景圆盘内核大小，数值越大模糊度越夸张明显，但同时性能消耗也更高（其内核越大，所使用的GPU时间越长）。 | Enumeration<br/>`0`: `Small`<br/>`1`: `Medium`<br/>`2`: `Large`<br/>`3`: `VeryLarge` |

<!-- tab:信号干扰 -->
### Grain

> **信号干扰**，模拟屏幕信号干扰时的雪花颗粒效果。

<img height="300" src="/Docs/lib/img/PostProcessing/Grain.png" alt="Grain Sample">

> [!TIP]
> 信号干扰过强会让画面过于噪点化。

```ini
; 下方参数均为默认值，直接套用将不会有任何效果

[Grain]
Colored=true
Intensity=0
Size=1
Luminance Contribution=0.8
```

| 配置项                      | 介绍                                                                                                      | 取值范围                       |
|--------------------------|---------------------------------------------------------------------------------------------------------|----------------------------|
| `Colored`                | 启用彩色颗粒，当值为<br/>`true`时噪点带有随机色彩颜色。                                                                        | Boolean<br/>`true` `false` |
| `Intensity`              | 控制噪点数量，数值越高强度越大。                                                 | Float<br/>`0.00 ~ 1.00`    |
| `Size`                   | 控制噪点颗粒大小，数值越大颗粒越明显。                                                                                    | Float<br/>`0.30 ~ 3.00`    |
| `Luminance Contribution` | 控制噪点随亮度变化的响应曲线，关卡内暗场景较多时适合数值低，使暗部噪点变少。 | Float<br/>`0.00 ~ 1.00`    |

<!-- tab:运动模糊 -->
### Motion Blur

> **运动模糊**，用于模拟物体在运动过程中产生的模糊效果。

> [!TIP]
> 运动模糊过强会让线体拐弯和收集碎片抽搐。

```ini
; 下方参数均为默认值，直接套用将会使用默认效果

[Motion Blur]
Shutter Angle=270
Sample Count=10
```
| 配置项             | 介绍                                                                 | 取值范围                      |
|-----------------|--------------------------------------------------------------------|---------------------------|
| `Shutter Angle` | 控制快门的角度，角度越大拖影越长越明显。   | Float<br/>`0.00 ~ 360.00` |
| `Sample Count`  | 控制模糊采样的数量，数值越高模糊越平滑但同时性能消耗越大。 | Integer<br/>`4 ~ 32`      |

<!-- tab:暗角 -->
### Vignette

> **暗角**，可以造成被渲染场景的亮度随距视角中心位置的距离增加而逐渐降低，使屏幕四个角落的亮度变暗。

<img height="300" src="/Docs/lib/img/PostProcessing/Vignette.png" alt="Vignette Sample">

> [!TIP]
> 暗角原色过强会让画面直接黑掉。

```ini
; 下方参数均为默认值，直接套用将不会有任何效果

[Vignette]
Color=#000000FF
Center=0.5,0.5
Intensity=0
Smoothness=0.20
Roundness=1
Rounded=false
```

| 配置项          | 介绍                                                                                                                       | 取值范围                                                                                       |
|--------------|--------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------|
| `Color`      | 暗角颜色，默认效果为纯黑。                                                                                                          | Color<br/>`#RRGGBBAA`                                                                      |
| `Center`     | 控制暗角的中心点位置，以屏幕中心为准坐标为[0.5,0.5]                                                            | Vector<br/>`x,y,z`<br/>`x`:`Float  -∞ ~ ∞`<br/>`y`:`Float  -∞ ~ ∞`<br/>`z`:`Float  -∞ ~ ∞` |
| `Intensity`  | 屏暗角的强度。                                                                                          | Float<br/>`0.00 ~ 1.00`                                                                    |
| `Smoothness` | 屏幕暗角边缘的平滑度，值越大越平滑。                                                                                      | Float<br/>`0.01 ~ 1.00`                                                                    |
| `Roundness`  | 控制暗角形状的阈值，当值为<br/>`1`时形状为圆形，反之值为<br/>`0`时形状为方形。                                                                            | Float<br/>`0.00 ~ 1.00`                                                                    |
| `Rounded`    | 若设置为<br/>`true`时强制为正圆形，反之若设置为<br/>`false`则会根据屏幕宽高比自动调整形状，自然贴合屏幕边框。 | Boolean<br/>`true` `false`                                                                 |
