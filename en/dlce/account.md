# Account System
<!-- last-modified -->

The game offers two account systems, for DLRS GAS Account system and Game Center（Only iOS）, iOS players can switch between different account systems through [Advanced Settings](/en/dlce/advanced.md#LoginMethod), Game progress does not share between different account systems.

## DLRS GAS Account System :id=dlrs-gas
- Provided by [The official website of DLRS Tongrong](https://chinadlrs.com);
- Provides Cloud Save, supports game progress synchronization across all DLCE platforms;
- Players need to log in when the game begins;
- Players need to log up an account on the website before they log in the game.

## Game Center
> [!IMPORTANT]
> Only support iOS

- Log in with The official Apple Game Center account;
- Cloud Save are provided by iCloud, and players need to enable iCloud read access for the game to support Cloud Save;
- Cloud Save is not compatible with other login methods, only be used for synchronization between games that use Game Center login on iOS devices;
- Automatically log in when the game begins, jump right into the game without any manual intervention from the player.
