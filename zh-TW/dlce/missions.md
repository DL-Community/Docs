# 日常任務
<!-- last-modified --> 

>遊戲玩法

## 任務規則
遊戲內共五項任務，除第1項和第2項綁定外，剩下三項任務每隔24小時隨機刷新一回。刷新的任務會從文件下方的任務列表中選取（不含固定任務），完成後給予對應的星星或者體力方塊。

## 任務列表

> [!TIP]
> 此文件列出所有完整任務，給予參考

| 任務項目                               | 取得               |
|---------------------------------------|-------------------|
| **登錄遊戲（綁定第一項）**                | **500 星星✨**     |
| **通關任意關卡1次（綁定第二項）**          | **100 星星✨**     |
| **通關任意關卡3次**                     | **200 星星✨**     |
| **消耗200星星**                        | **200 星星✨**     |
| **在任意關卡中收集20顆鑽石**              | **200 星星✨**     |
| **在任意關卡中收集6個皇冠**               | **200 星星✨**     |
| **在任意關卡中死亡10次**                 | **200 星星✨**     |
| **在任意關卡中復活5次**                  | **200 星星✨**     |
| **消耗15個方塊**                       | **20 體力方塊**     |

## 補充
- “日常任務”位於主菜單功能首個，也可以從[星星](/zh-TW/dlce/coins.md#star)界面和[體力方塊](/zh-TW/dlce/coins.md#cube)界面轉移。
- 每項任務完成後任務項漸灰終止。
