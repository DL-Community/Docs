## 製作設定檔
- [加入QQ群](https://qm.qq.com/q/wlrTgLHAHI)在群檔案中尋找自訂後處理的設定檔模板；
- 在其基礎上修改數值後並**匯入對應的路徑中**即可；
- [設定檔內的各項設定描述在這裡](#設定檔介紹)；
- 設定完畢後，繼續閱讀下文將檔案重新命名並匯入至遊戲。

## 匯入設定檔
  <!-- tabs:start -->
  <!-- tab:Windows -->
### Windows 路徑
- 前往遊戲安裝目錄（安裝時指定的路徑）。
- 後處理設定檔儲存在

```directory
Dancing Line/Dancing Line_Data/Custom/PostProcessing/關卡代號.bytes
```

  <!-- tab:iOS -->
### iOS 路徑
- 開啟「檔案」app，找到「我的iPhone」
- 後處理設定檔儲存在

```directory
跳舞的線/Custom/PostProcessing/關卡代號.txt
```

  <!-- tab:iPad -->
### iPad 路徑
- 開啟「檔案」app，找到「我的iPad」
- 後處理設定檔儲存在

```directory
跳舞的線/Custom/PostProcessing/關卡代號.txt
```

  <!-- tab:iOS on Mac -->
### iOS on Mac 路徑
- 開啟 Finder，按下 `Command + Shift + G`，輸入下列路徑並按下 Enter：

````directory
~/Library/Containers
````

- 找到遊戲資料夾，進入 `Data/Documents` 資料夾。
- 後處理設定檔儲存在

```directory
Custom/PostProcessing/關卡代號.txt
```

## 製作設定檔
- [加入QQ群](https://qm.qq.com/q/wlrTgLHAHI)在群檔案中尋找自訂後處理的設定檔模板；
- 在其基礎上修改數值後並**匯入對應的路徑中**即可；

## 匯入設定檔
### Windows 路徑
- 前往遊戲安裝目錄。
- 後處理設定檔儲存在

```directory
Dancing Line/Dancing Line_Data/Custom/PostProcessing/關卡代號/postprofile.bytes
```

<!-- tabs:end -->

### 注意事項

- 其中 `關卡代號` 用於指定該設定將會用於哪一個關卡。比如，將 `關卡代號` 替換為 `Taurus`，則遊戲會將你的設定檔應用在**金牛座**關卡中。
- 更多 `關卡代號` 見[關卡資訊](/zh-TW/dlce/level_information.md)。
- `關卡代號` 必須使用指定的名稱，否則不會正常讀取。
- 遊戲允許同時匯入多個設定檔，並自動應用到 `關卡代號` 對應的關卡上。

## 設定檔介紹

- Profile中每一個不同的特效的設定都會使用 {} 進行包括，例如下文中被{}包括的內容則是與antialiasing有關的設定參數

```json
      "antialiasing": {
        "m_Enabled": false,
        "m_Settings": {
          "method": 0,
              "fxaaSettings": {
                "preset": 2
            },
          "taaSettings": {
            "jitterSpread": 0.75,
            "sharpen": 0.30000001192092898,
            "stationaryBlending": 0.949999988079071,
            "motionBlending": 0.8500000238418579
          }
        }
      },
```

### 通用設定項

#### m_Enabled

- `m_Enabled`：每一個特效設定中都有此設定項，用於控制是否開啟該特效。`true` 為開啟，`false` 為關閉

```json
      "m_Enabled": false,
```

#### m_Settings

- `m_Settings`：每一個特效設定中都有此設定項，用於調整該特效的具體參數（只有 `m_Enabled` 為 `true` 時才會生效）

```json
      "m_Settings": {
         ...
      }
```

#### intensity

- `intensity`：位於 `m_Settings` 中，大部分特效設定都有此設定項，用於調整該特效的強度

```json
      "intensity": 1.0,
```

#### radius

- `radius`：位於 `m_Settings` 中，大部分特效設定都有此設定項，用於調整該特效的影響範圍

```json
      "radius": 0.3,
```

### 效果設定項

> [!WARNING]
> 開啟任一特效均會對遊戲幀數產生影響，請在開啟前考慮裝置效能

#### Anti-Aliasing

> **抗鋸齒（AA）**，開啟該特效可讓遊戲畫面更加細膩，但同時也會造成一定的裝置效能損耗。

- `method`: 抗鋸齒模式, 參數範圍 `整數 0 - 1`，`0-快速近似抗鋸齒（FXAA）`，`1-時域抗鋸齒（TAA）`。


- `fxaaSettings`：FXAA相關設定，僅在使用了FXAA模式生效。
  - `preset`：FXAA模式，參數範圍 `整數 0 - 4`，`0-最佳效能` `1-效能` `2-預設` `3-品質` `4-最高品質`。


- `taaSettings`：TAA相關設定，僅在使用了TAA模式生效。
  - `jitterSpread`：TAA取樣範圍，參數範圍 `浮點數 0 - 1`，數字越小，畫面越清晰，但鋸齒更多，反之亦然。
  - `sharpen`：畫面銳化，參數範圍 `浮點數 0 - 3`。
  - `stationaryBlending`：固定畫素取樣的混合係數。控制混合到最終顏色的歷史取樣的百分比。參數範圍 `浮點數 0 - 0.99`，
  - `motionBlending`：動態畫素取樣的混合係數。控制混合到最終顏色的歷史取樣的百分比。參數範圍 `浮點數 0 - 0.99`，

> [!WARNING]
> 請勿在遊戲內建MSAA（僅PC可用）開啟的情況下啟用此抗鋸齒功能

````json
"antialiasing": {
    "m_Enabled": false,
        "m_Settings": {
            "method": 0,
            "fxaaSettings": {
                "preset": 2
            },
            "taaSettings": {
            "jitterSpread": 0.75,
            "sharpen": 0.30000001192092898,
            "stationaryBlending": 0.949999988079071,
            "motionBlending": 0.8500000238418579
        }
    }
 },
````


#### Ambient Occlusion

> **環境光遮蔽（AO）**，開啟該特效可在物體邊緣繪製陰影，增加畫面層次感。

- `intensity`：強度，參數範圍 `浮點數 0 - 4`


- `radius`：範圍，參數範圍 `浮點數 0 - 無限（取決於目前裝置的最大浮點數上限）`


- `sampleCount`：取樣級別，參數範圍 `整數 0 - 3`，`0-最低` `1-低` `2-中` `3-高`。


- `downsampling`：對物體向下的面進行取樣，參數 `true` `false`，可根據情況選擇是否開啟


- `forceForwardCompatibility`：強制前向相容性，參數 `true` `false`，可根據情況選擇是否開啟


- `ambientOnly`：僅前向光，參數 `true` `false`，可根據情況選擇是否開啟


- `highPrecision`：高精度模式，參數 `true` `false`，可根據情況選擇是否開啟


> [!TIP]
> 環境光遮蔽不應過強，否則會導致畫面變黑變髒，影響視覺效果。

````json
"ambientOcclusion": {
    "m_Enabled": false,
    "m_Settings": {
        "intensity": 1.0,
        "radius": 0.30000001192092898,
        "sampleCount": 10,
        "downsampling": true,
        "forceForwardCompatibility": false,
        "ambientOnly": false,
        "highPrecision": false
    }
},
````

#### Depth of Field

> **景深**，用於模擬人眼以及相機的背景模糊效果。

- `focusDistance`：焦點距離，參數範圍 `浮點數 0.1 - 無限（取決於目前裝置的最大浮點值上限）`


- `aperture`：Aperture（F-stop），攝影機鏡頭光圈的大小，參數範圍 `浮點數 0.1 - 32`


- `focalLength`：Focus Length (mm)，焦距（毫米），參數範圍 `整數 1 - 300`


- `useCameraFov`：使用遊戲攝影機的視野（FOV），參數 `true` `false`，可根據情況選擇是否開啟，開啟後 `focalLength` 不再生效


- `kernelSize`：參數範圍 `整數 0 - 3`，`0-小` `1-中` `2-大` `3-最大`。

````json
"depthOfField": {
    "m_Enabled": false,
    "m_Settings": {
        "focusDistance": 10.0,
        "aperture": 5.599999904632568,
        "focalLength": 50.0,
        "useCameraFov": false,
        "kernelSize": 1
    }
},
````

#### Motion Blur

> **運動模糊**，用於模擬物體在運動過程中產生的模糊效果。

````json
"motionBlur": {
    "m_Enabled": false,
    "m_Settings": {
        "shutterAngle": 270.0,
        "sampleCount": 10,
        "frameBlending": 0.0
    }
},
````

#### Bloom

> **物體外發光效果**，也叫**光溢位**，用於模擬物體在高亮度情況下的發光效果。

````json
"bloom": {
    "m_Enabled": false,
    "m_Settings": {
        "bloom": {
            "intensity": 0.5,
            "threshold": 1.100000023841858,
            "softKnee": 0.5,
            "radius": 4.0,
            "antiFlicker": false
        },
        "lensDirt": {
            "texture": {
                "instanceID": 0
            },
            "intensity": 3.0
        }
    }
},
````

> [!NOTE]
> bloom過強會導致畫面過亮並變糊，不建議過度使用。

#### Color Grading

> **色彩分級**，用於矯正/調整場景顏色，其中的xyz參數代表了顏色的rgb值，透過調整其中的值（**取值範圍0-1**）以達到你想要的色彩。

#### Chromatic Aberration

> 色差，用於模擬相機鏡頭散射現象，使得物體邊緣產生類似彩虹的顏色

#### Vignette

> Vignette 效果可以造成被渲染場景的亮度隨距視角中心位置的距離增加而逐漸降低，使螢幕四個角落的亮度變暗。
