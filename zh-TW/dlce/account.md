# 帳戶系統
<!-- last-modified -->

遊戲提供兩種登入方式：DLRS 同人遊戲通用帳戶系統，以及 Game Center（僅限 iOS）。iOS 玩家可以透過[進階設定](/zh-TW/dlce/settings/advanced.md#登入方式)切換登入方式；不同登入方式之間的進度不互通。

## DLRS 同人遊戲通用帳戶系統 :id=dlrs-gas
- 由 [DLRS 同人群官方網站](https://chinadlrs.com)提供服務；
- 提供雲存檔，支援 DLCE 全平台進度同步；
- 遊戲啟動時需要玩家進行登入；
- 玩家需要前往網站註冊帳戶後才能登入遊戲。

## Game Center
> [!IMPORTANT]
> 僅支援 iOS

- 使用 Apple 提供的 Game Center 身分登入；
- 雲存檔由 iCloud 提供，玩家需要開啟遊戲的 iCloud 讀寫權限才能支援雲存檔；
- 雲存檔與其他登入方式不互通，僅能在 iOS 裝置使用 Game Center 登入的遊戲之間進行同步；
- 遊戲啟動時自動登入，直接進入遊戲，無需玩家手動干預。
