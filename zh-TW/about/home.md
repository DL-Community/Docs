## 系統需求

<!-- tabs:start -->

<!-- tab:Windows -->
> [!NOTE]
> 需要 64 位處理器和作業系統

> [!WARNING]
> 遊戲不相容 Windows 7 及以下的作業系統

> [!CAUTION]
> 遊戲需要安裝 [Microsoft VC++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-supported-redistributable-version) 執行庫才能執行

### 建議配備
- **作業系統**：Windows 11 64 位元
- **處理器**：Intel Core i5-2400 3.1GHz / AMD Radeon FX-8120 3.1GHz 或更高規格
- **圖形 API**：Direct3D12
- **顯示卡**：NVIDIA GTX 1060／AMD Radeon RX 480 或更高規格
- **記憶體**：8 GB RAM 或更高規格
- **儲存空間**：需要 5 GB 可用空間
- 建議將畫質調整至「極高」或「極限」以獲得最佳遊戲體驗
- 顯示器更新率達 120 Hz 以上時，建議開啟垂直同步
- 若要使用 DirectX 12 API，必須使用 Windows 10（Version 1809 以上），且 GPU（圖形處理器）的 VRAM 容量需達 4 GB 以上

### 最低配備
> [!WARNING] 
> 最低配備無法保證完整遊戲體驗
- **作業系統**：Windows 8 64 位元
- **處理器**：Intel Core i5-2400 3.1GHz / AMD Radeon FX-8120 3.1GHz
- **圖形 API**：Direct3D11 或 OpenGLCore
- **顯示卡**：NVIDIA GeForce GTX 750 Ti / AMD Radeon HD 6950
- **記憶體**：4 GB RAM
- **儲存空間**：需要 4 GB 可用空間
- 建議將畫質調整至「高」或更低，以維持流暢度
