## システム要件

<!-- tabs:start -->

<!-- tab:Windows -->

> [!NOTE]
> 64 ビット対応のプロセッサとオペレーティングシステムが必要です。

> [!WARNING]
> Windows 7 以前のオペレーティングシステムには対応していません。

> [!CAUTION]
> Windows でゲームを実行するには、[Microsoft Visual C++ 再頒布可能パッケージ](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-supported-redistributable-version)が必要です。

### 推奨環境

- **オペレーティングシステム**：Windows 11 64 ビット
- **プロセッサ**：Intel Core i5-2400 3.1 GHz / AMD Radeon FX-8120 3.1 GHz 以上
- **グラフィックス API**：Direct3D 12
- **グラフィックスカード（GPU）**：NVIDIA GTX 1060／AMD Radeon RX 480 以上
- **メモリ**：8 GB RAM 以上
- **ストレージ**：5 GB 以上の空き容量
- 最適なゲーム体験のため、画質を「Ultra」または「Maximum」に設定することを推奨します。
- リフレッシュレートが 120 Hz 以上のモニターでは、垂直同期を有効にすることを推奨します。
- DirectX 12 API を使用するには、Windows 10（バージョン 1809 以降）と 4 GB 以上の VRAM を搭載した GPU が必要です。

### 最低環境

> [!WARNING] 
> 最低環境では、完全なゲーム体験を保証できません。

- **オペレーティングシステム**：Windows 8 64 ビット
- **プロセッサ**：Intel Core i5-2400 3.1 GHz / AMD Radeon FX-8120 3.1 GHz
- **グラフィックス API**：Direct3D 11 または OpenGLCore
- **グラフィックスカード（GPU）**：NVIDIA GeForce GTX 750 Ti / AMD Radeon HD 6950
- **メモリ**：4 GB RAM
- **ストレージ**：4 GB 以上の空き容量
- フレームレートを維持するため、画質を「High」以下に設定することを推奨します。
